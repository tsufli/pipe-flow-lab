What is being shown?

For each saved DNS snapshot, the displayed field is the fluctuation kinetic energy density on a pipe cross-section:

k′ = ½[(u_z-u_{z,lam})² + u_r² + u_θ²]

Here u_{z,lam}(r)=1-r² is the laminar Hagen–Poiseuille profile in the solver normalization. Because dnsjax stores the perturbation field for pipe flow, the analysis directly reads the fluctuation components and evaluates k′.

The shown section is the mid-plane in the periodic axial direction. Each run is assembled into an animated GIF so the appearance and decay of finite-amplitude structures can be followed through time.
