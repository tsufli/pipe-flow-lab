Model and numerical parameters

Numerical method and assumptions

Periodic domain of length L with N uniformly spaced cell centers. The q advection term is discretized with first-order upwind differences using the local speed u−ζ. The u equation is advanced in conservative form using a local Rusanov flux for u²/2. Diffusion of q uses a centered second difference. A two-stage explicit Runge–Kutta (Heun) update advances the coupled semi-discrete system. The integration step is chosen conservatively from both the maximum advection velocity and the explicit diffusion limit; calculations run in the browser in bounded chunks to keep the page responsive. The temporal-resolution slider controls the saved frame spacing Δt_save = T / (number of intervals), not the numerical integration time step; frames are interpolated from successive integration states, so snapshot spacing does not determine the integration trajectory. Initial data are a smooth localized plateau in q with u(x,0)=U₀. An optional overlay numerically relaxes a separate zero-noise puff and approximates the unstable decay edge using 18 bisections between puff-like and laminar initial conditions, at the currently selected physical PDE parameters. The resulting candidate is sampled during its near-separatrix transient and is not guaranteed to be an exact traveling-wave edge. The solver rejects references that are not sufficiently localized or persistent. All reference profiles are shifted periodically to match the displayed frame center of mass and hidden when the center is ill-defined. The equations model cross-sectionally reduced pipe dynamics, not 3D Navier–Stokes DNS. Boundary interactions become relevant once the pulse reaches the periodic seam. For σ > 0, each step adds independent Gaussian increments σq √(Δt/Δx) Z, with Z ~ N(0,1), interpreted as Itô noise and normalized for space-time white covariance. The stochastic update is Euler–Maruyama applied after the deterministic Heun step, so its stochastic accuracy is first order in the weak sense rather than deterministic RK2. Each noisy run generates a new pseudorandom seed, displayed beside the Run button, so repeated runs with unchanged parameters give different realizations. Deterministic runs (σ = 0) remain identical. Noise may produce slightly negative q values; no artificial positivity clipping is performed. Results depend on resolution, and noise-sensitive conclusions require convergence and ensemble tests.
