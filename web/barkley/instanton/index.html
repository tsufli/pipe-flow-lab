Read the experiment

Both experiments solve the same discretized stochastic control problem over the unconstrained grid of 320 time cells × 160 spatial cells:

qₜ = Fq(q,u) + q a(x,t),   uₜ = Fu(q,u),   I[a] = ½ ∫dt dx a².

Minimize J[a] = I[a] + (ρ/2)‖(qT,uT) − translated edge‖², with the u-field weighted by 3 and the translation found using the first Fourier moment of q. Final-time matching is therefore soft. The action is not a Gaussian ansatz, and all control-grid values are independently optimizable.

The two initial *reference histories* are a smooth linear interpolation of puff and edge profiles, and the time reversal of the deterministic edge→puff unstable branch. Neither is an admissible q/u stochastic history. We invert the q-equation along each reference q history while integrating u deterministically, then scale the inferred control by 0.05 to avoid numerical instability. You can inspect the unscaled reference q shapes by selecting a seed and comparing its dashed reference curve at any time.

Only local numerical minimizers of a fixed-horizon, penalized objective have been attempted. The terminal distance is nonzero; the last high-penalty iterates are not all strictly gradient-converged. Same-action or similar-path observations do not certify a unique global instanton or continuum convergence. Each curve is an actual PDE rollout from an optimized forcing field; no u-noise is introduced.
